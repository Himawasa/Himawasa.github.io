GOAL

このプロジェクトで何を実現するか

😫

現在の課題

顧問先ごとにバラバラな形式の賃金データを、毎月手作業でシャルフに入力している。時間がかかり、ミスが起きやすく、新人への教育も大変。

🎯

解決策

Pythonプログラムで自動変換。どんな形式のデータでも、シャルフに取り込めるCSVファイルを自動生成する。

✨

メリット

作業時間の大幅短縮、入力ミスゼロ、スタッフの属人化を解消。新しい顧問先にも設定ファイルの追加だけで対応可能。

シャルフのテンプレートは全54列ですが、東様の検証により必要なのは10項目だけと判明しました。

4給与支給日支給日支給日実行時に指定コピー

DATA FORMAT

データの構造：縦並びと横並び

今回の4つのサンプルは、実は2つのパターンだけです。

🟢 給与奉行 ＝ 縦並び（1行＝1人）

────────────────────────
   5    田中太郎  20   208,881
  24    鈴木花子  20   373,984

→ 上から順に読むだけでOK
→ 普通のExcel表と同じ感覚
🟡 弥生給与 ＝ 横並び（1列＝1人）

ARCHITECTURE

プログラムの仕組み

⚙️

convert.py（プログラム本体）

データを読んで、変換して、CSVに出す処理。ここは変更不要。1つだけで全パターンに対応。

📋

JSON（設定ファイル）

「出勤日数 → 労働日数にコピー」のような変換ルール。顧問先ごとに1ファイル作成。

JSONファイルの中身はとてもシンプルです：

変換ルール①：そのままコピー
"労働日数": {
  "元の列名": "出勤日数",
  "方法": "そのままコピー"
}

→ 入力の「出勤日数」を
  シャルフの「労働日数」にコピー
変換ルール②：複数列を合算
"休日労働日数": {
  "元の列名": ["休日出勤日数",
              "法休出勤日数"],
  "方法": "足し算して合算"
}

→ 2つの列を足して1つにまとめる
🔧 新しい顧問先の追加方法：JSONファイルをコピーして、列名を書き換えるだけ。プログラムの知識がなくても対応できます。
