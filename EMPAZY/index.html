なぜ先にフォルダを決めるの？
レシートの原本（写真そのもの）は、御社の SharePoint に置いたままにします。
Google など、別の場所にはコピーしません。置き場所が分かってから、アプリをお送りします。
※レシート写真にはカード情報なども含まれるため、情報保護とプライバシーの観点から、岩城が直接フォルダの中身を見ることはいたしません。そのためフォルダの共有（招待）手続きは不要です。画面上のURLだけを教えていただければ設定できますのでご安心くださいね。

「経費レシート」フォルダを作る

SharePoint は、会社のみんなで使える「インターネット上の書類棚」のような場所です。

  1. パソコンで Microsoft Edge か Google Chrome を開きます。
  2. いつもの会社の SharePoint（または「ドキュメント」「共有フォルダ」）を開きます。
  3. 経費を置きたい場所で、「新規」→「フォルダー」 を押します。
  4. 名前は 経費レシート と入力して作成します。
すでに経費用のフォルダがある場合は、新しく作らなくて大丈夫です。
そのフォルダを使う旨と、次の手順の URL を教えてください。

2

池田様のパソコンに同期する

「同期」とは、インターネット上のフォルダが、自分のパソコンのエクスプローラーにも見えることです。
一度設定すれば、スマホやブラウザで入れた写真が、パソコンにも出てきます。

  1. 手順1のフォルダを、ブラウザで開いたままにします。
  2. 画面の上のほうにある 「同期」 を押します。
  3. 「OneDrive を開きますか？」と出たら 「開く」 を押します。
    少し待つと白い画面が出ることがあります。サインインを求められたら、会社のメールで入ってください。
    ※裏でパソコンが準備しているため、画面が変わるまで十数秒ほど時間がかかることがあります。そのまま少し待ってみてくださいね。
  4. パソコンの「エクスプローラー」（黄色いフォルダのアイコン）を開きます。
  5. 左の一覧に 会社名や OneDrive / SharePoint が出て、その中に 経費レシート があれば成功です。
できたかどうかの目印です。フォルダの横や、名前の右に次のどちらかが出ていれば大丈夫です。

3

ブラウザの URL をコピーして送る

いよいよ最後のステップです。ここでコピーしていただくアドレスをもとに、スマホ撮影アプリとフォルダをつなぎます。

  1. もう一度、ブラウザで 経費レシート フォルダを開きます。
    （フォルダをダブルクリックして、中に入った状態です）
  2. 画面のいちばん上、長い文字が並んでいる欄を見てください。ここが URL（アドレス） です。
  3. その欄を 1回クリック すると、全体が青くなります。
    青くなったら、右クリック → コピー します。
    （青くならないときだけ、マウスでなぞって選んでください）
  4. 岩城へのメールに貼り付けて送ってください。
    いただいた URL をもとに、スマホ撮影アプリの送信先をこちらでつなぎます。
ここをコピーします（黄色い部分のイメージ）
https://御社の名前.sharepoint.com/sites/…/経費レシート
経費レシート

送っていただく文字の例です。御社の名前の部分は、実際と違っていて大丈夫です。

https://contoso.sharepoint.com/sites/keiri/Shared%20Documents/経費レシート
URL は、必ず https:// から始まります。
コピーすると「%」や英数字がずらりと並んで暗号のように見えることがありますが、文字化けではありませんのでご安心ください。そのままメールに貼り付けて送っていただければ大丈夫です。
※「C:\」などから始まるパソコン内の場所とは異なりますので、そちらは送らなくて大丈夫です。

送る前の確認

印刷した紙では、左の四角をペンで塗って使ってください。

フォルダの共有（招待）はせず、URLだけをメールに貼った（岩城が見ることはありませんのでご安心ください）
