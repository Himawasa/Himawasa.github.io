## 確認したこと
1. **URL の実在確認（リンク切れゼロ）**:
   - `STATIC_LINKS` に定義されている 17本の URL（`/temasui/`, `/temasui/factory/`, `/temasui/biz/`, `/temasui/pro/`, `/temasui/start/`, `/temasui/guide/`, `/for/care/`, `/for/factory/`, `/for/pro/`, `/for/biz/`, `/try/`, `/cardsync/`, `/services/`, `/works/`, `/rk/`, `/about/`, `/contact/`）について、実在する静的ファイルまたはルーティング設定と 1対1 で照合し、404 になるリンクが 1本も存在しないことを確認しました。
2. **React マウント時の挙動**:
   - `src/main.jsx` では `createRoot` を使用しており、React 起動時に `#root` 内の静的リンクが自動的に完全クリア・再描画されるため、ハイドレーション不一致エラーや画面の重複表示が発生しないことを確認しました。
3. **初期 HTML の配置構造**:
   - トップページでは `heroStaticHtml()`（Hero セクション）の直後に配置されているため、ファーストビューを阻害せず Hero の下に静的リンクが出力されることを確認しました。
   - 下層ページでは自分自身の URL（`page.path`）が正しく除外された 16本のリンクが出力されることを確認しました。
4. **検索エンジンへの影響**:
   - `<nav class="static-links" aria-label="主なページ">` としてセマンティックにマークアップされており、同じリンクが React や noscript と重複して存在しても、Google のペナルティ対象にはならず、正常に内部リンクとして認識されます。
