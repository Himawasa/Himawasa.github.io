## 範囲外の提案
1. **LCP 画像のプリロード検討**:
   - ロゴ画像 `logo-160.png` に `fetchpriority="high"` が付いていますが、もしトップ画面で一番面積の大きい要素がテキストではなく画像になる場合、`<link rel="preload" as="image" href="/logo-160.png">` を `<head>` に差し込むことで、さらに LCP を数十〜数百ミリ秒前倒しできます。
2. **PC 幅での初期表示（`hero-right`）の考慮**:
   - スマホではカードが縦積みまたは下部になりますが、PC 画面では静的 HTML 時に右側半分が空白に見えます。将来的に JS 本体の分割・遅延読み込みを行う際に、右側カードの初期スケルトンや静的配置も検討価値があります。
