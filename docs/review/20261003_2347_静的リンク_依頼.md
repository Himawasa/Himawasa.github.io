## 1. 何をしたか・なぜか
岩城さんが貼った Search Console の「ページのインデックス登録」で、**てますいの10ページ（本体・工場版・中小企業版・士業版・始め方・書き方ガイド5本）が1つも Google に登録されていない**と分かった（登録済み28・未登録13。最後の巡回は 9/22）。ページの設定（200・index・canonical）は正しい。
原因の1つとして、このサイトはメニューや本文を JavaScript で作るため、**JS が動く前の HTML には てますい へのリンクが1本も無い**（下層ページは `<div id="root"></div>` だけ）。Google は JS を動かすが、小さなサイトは後回しにされやすい。
対策として、トップと下層ページ全部の最初の HTML（`#root` の中）に、主なページへのリンク17本（`STATIC_LINKS`）を静的に入れた。React が起動すると `#root` ごと置き換わるので、画面には残らない。あわせて `<noscript>` のメニュー（`navHtml`）に てますい・工場 を足した。
