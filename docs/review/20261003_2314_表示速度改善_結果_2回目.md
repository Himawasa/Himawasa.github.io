## 確認したこと（指摘対応の検証結果）
1. **【指摘 1対応：GA4 タグ読み込み】**:
   - `var done = false; if (done) return; done = true;` により、操作イベント（`pointerdown`, `keydown`, `scroll`, `touchstart`）と `setTimeout(go, 2500)` のいずれかが先に発火しても、二重読み込み（多重 script 挿入）が発生しないことを確認しました。
   - 初回ユーザー操作で即座に読み込まれるため、操作離脱時の計測漏れリスクが大幅に低減されています。
2. **【指摘 2対応：静的 HTML への `.hero-paths` 追加】**:
   - `HERO.paths` を定義して `heroStaticHtml` と `Hero.jsx` で共有し、初期 HTML に `<div class="hero-paths">`（リンク 4件）が正しく出力されることを確認しました。React 起動前後でレイアウトシフト（CLS）が発生しない状態になっています。
3. **【指摘 3対応：タイピング初期表示のチラつき解消】**:
   - 初期 HTML に `PHRASES[0]`（'毎月の手作業を、もっと短く。'）を出力し、React 側の `TypingText` を `text = PHRASES[0]`, `phase = 'pause'` から開始するように修正されていることを確認しました。マウント時に文字が一度消えるチラつきが解消され、400ms 後に自然に消去・次のフレーズのアニメーションへと繋がります。
4. **【指摘 4対応：`esc()` 関数のダブルクォートエスケープ】**:
   - `replace(/"/g, '&quot;')` が追加され、HTML 属性値埋め込み時のエスケープが強化されたことを確認しました。
5. **【指摘 5対応：Node.js 環境用注意書き】**:
   - `heroText.js` の冒頭に「vite.config.js から直接 import されるため、React Hooks・JSX・CSS import を書いてはならない」旨の注意書きが明記されたことを確認しました。

## 岩城さんへの判断事項（白ヤギからの相談点）
- **GA 読み込み遅延時間（2.5秒 vs 1秒）について**:
  - 現在の実装では「ユーザーが画面を操作（タップ・クリック・スクロール等）した瞬間」、または「操作が一切ないまま 2.5秒経過した時点」で計測タグが読み込まれます。
  - 「ページを開いて 2.5秒以内に画面を一切触らずにタブを閉じた」極めて早い直帰については計測から外れます。これを許容するか、より短い「1秒」にするかは、表示速度（Lighthouse 点数）とのバランスを見て岩城さんにご判断いただく必要があります。
    - **2.5秒のまま**: 低速回線でのパフォーマンススコアを最大限維持しやすい。
    - **1.0秒に短縮**: 即離脱の捕捉率は上がるが、遅い端末での初期描画完了直後にスクリプト読み込みが重なる可能性がわずかに上がる。
