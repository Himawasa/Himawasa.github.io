1. これは何ですか

いまお使いの消耗品注文を、仕事の流れを崩さずに良くするための見本です。

お客さまが迷わず注文できて、事務と倉庫が「受注表と伝票番号」だけで出荷まで辿れること。それが合格の目安です。

学校の名前、注文、金額はすべて架空です。いまの取引単価ではありません。

2. 触り方

パスワードは、どれも demo です。

だれメール見えるもの

おすすめの順です。

  1. さくら台でログインして、リボンを1本注文する
  2. ログアウトして、社内のメールで入り、受注管理表に行が増えているか見る
  3. 「出荷」に切り替え、発送伝票番号を入れる
  4. 受注管理表に、伝票番号が残っているか見る

お客さまのログイン画面には、社内メニューのことは出ません。

3. いまできること

お客さま

迷わず注文

自分のプリンタに合うものだけが出ます。枚数から本数も出せます。

事務

受注管理表

注文が入ると1行増えます。印刷して、倉庫へ渡せます。

倉庫

出荷と伝票

箱を出したら、発送伝票番号を入れて事務に戻します。

お客さまがログインする

→ 登録プリンタに合う消耗品だけが出る

→ 注文する（送料は合計で決まる）

→ 受注管理表が自動でできる

→ 事務が印刷し、請求書と一緒に倉庫へ持っていく

→ 倉庫が出荷し、発送伝票番号を書く

→ 事務に戻す

お客さま

  • プリンタは1台だけ（7650と7000の両方は持ちません）
  • 合う消耗品だけが出ます。型番が大きく、リボンは写真つきです
  • 枚数を入れると、必要なリボンの本数が分かります
  • 支払いは請求書です。画面で決済はしません
  • 注文のあと、受注番号の控えが出ます
  • 履歴から「前回と同じ内容」をカートに戻せます
  • メモと、発送の目安（翌営業日）が出せます
  • 2月・3月は新年度前で発行が多い、という案内の場所も用意しています

事務

  • 受注管理表を見て、印刷できます
  • 1件だけの受注票も出せます（倉庫へ渡す紙の代わり）
  • 請求案内の見本もあります（本物の請求書ではありません）
  • 受注番号やお客さまの名前で探せます
  • 表をCSVで出せます（Excelに貼れます）

倉庫

  • まだ出していない注文が一覧になります
  • 発送伝票番号を入れると、事務の表に残ります
  • 届け先と、未出荷の一覧を印刷できます

4. 商品と送料

見本では、再転写の2機種だけです。お客さまはどちらか一方だけ持ちます。

プリンタ見本のお客さま
DCP-7000さくら台高等学校（架空）
DCP-7650みどり学園（架空）
品番内容枚数目安
DCR2100CKN(B)よく使うリボン片面 約1,000枚／両面 約500枚
DCR2100PONピールオフのリボン片面 約750枚／両面 約325枚
クリーニング3種カードやキット10枚入りなど

リボンの見本単価は、税別 56,000円です。いまの定価ではありません。

送料は、商品合計が税別1万円以上なら発送元持ち（0円）。未満は一律1,000円です。

7000／7650 は、1,000枚に1回クリーニングします。カードは10枚で1セット。リボン10本で1セット、と案内します。

5. これから（今後の展開）

いま見本で流れを確かめる

お客さま → 注文 → 受注管理表 → 伝票番号まで、画面で触れます。

いまは見本なので、注文はこの端末の中にだけ残ります。本番では、事務と倉庫が別のパソコンでも同じ一覧を見られるようにします。

次現場に合わせて広げる

  • 代理店のお客さまも、同じ画面で注文できるようにする（お客さまは直販か代理店かを意識しなくてよい）
  • どのお客さまが、どのプリンタを何台持っているかを、きちんと管理する
  • 現場に残っている古い機種や、品番の数を増やす
  • 印刷する紙を、今の現場の帳票に近づける

そのあとあとからでよいこと

  • 発行のパソコンはオフラインなので、機械から自動で数字を取るのは今はやらない
  • 将来やるなら、「何枚出したか」だけ。顔や名前は使いません
  • 枚数が分かれば、「そろそろ切れる」とお知らせできる
