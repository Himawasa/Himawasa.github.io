2つの Power Automate を、使い分けます

パソコンの画面で人がしている操作はデスクトップ版、Microsoft 365 の中のやり取りはクラウド版が得意です。どちらが合うかは、今の作業を拝見してからご提案します。

デスクトップ版

パソコンの操作を、そのまま自動に

  • Excel から業務ソフトの画面への転記
  • 毎月のファイルを開いて集計し、決まった様式に貼る
  • 届いた PDF やファイルの名前を付け直して、決まったフォルダへ
  • 決まった手順の画面操作のくり返し
クラウド版

Microsoft 365 の中のやり取りを、自動に

  • Forms の回答を Excel の台帳に書き足す
  • Outlook に届いた添付ファイルを OneDrive や SharePoint に保存
  • Teams やメールで、担当の人にお知らせ
  • 申請と承認の流れ（届いたら上長へ、承認されたら記録）

てますいと組み合わせると

文章を考えて書くところは てますい、その先の決まった作業は Power Automate が受け持ちます。

てますいと Power Automate は直接つなぎません。人が確かめた文章だけが、その先の作業に流れるようにしています。

よくあるご質問

Power Automate を使うのに、追加のお金はかかりますか？
デスクトップ版は、Windows 10／11 なら追加費用なしで使えます。クラウド版は、Microsoft 365 の会社のアカウントがあれば、基本の連携（標準のコネクタ）は追加費用なしで使えます。夜間に無人で動かす使い方や、一部の連携（プレミアムのコネクタ）には、Microsoft の有料ライセンスが別に要ります。必要かどうかは、作る前にお伝えします。
Mac でも使えますか？
デスクトップ版は Windows 専用です。クラウド版はブラウザで動くので、Mac からも作ったフローを使えます。
今あるフローが止まってしまいました。直してもらえますか？
はい、拝見します。画面やファイルの形が変わって止まることが多いので、どこで止まっているかを一緒に確かめてから直します。
お客さまの情報は、外に出ませんか？
作ったフローは、お客さまの パソコンと Microsoft 365 の中で動きます。HiMaWaSa Sync のサーバーにデータを送る作りにはしません。作るときは見本のデータを使います。
てますいと Power Automate は、つながっているのですか？
直接はつなぎません。てますいで作った下書きを人が確かめてから貼り、その先の転記・集計・通知を Power Automate が受け持つ形です。確かめていない文章が自動で流れていかないようにするためです。
