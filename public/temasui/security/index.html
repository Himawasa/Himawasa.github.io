セキュリティとデータの取り扱い

てますい（介護施設・病院・工場・中小企業・士業事務所向けのアシスタント）で、お預かりするデータをどこに置き、どう守っているかをまとめました。院内・社内でのご確認や稟議に、このまま印刷してお使いいただけます。

提供：HiMaWaSa Sync（大阪府）／最終更新：2026年10月　

住所をどこまで書くか（今は「大阪府」だけ）

1. どこで動き、どこに保存するか

動く場所Google Cloud の東京リージョン（日本国内のデータセンター）
データの保存場所Google Cloud の東京リージョン。名簿・予定・持ち物の一覧と写真・紹介状の一覧を、会社・施設ごとに分けて保存します
AI の処理Google Cloud の生成 AI（Vertex AI）を使います。入力した内容が AI の学習に使われることはありません。AI には処理のために一時的に送り、AI 側には保存されません。
処理の場所は、国内に限っていません（国外のデータセンターを使うことがあります）。ただし、士業事務所向けは、ご契約後は国内（東京）で処理します。病院向けも、ご希望があれば国内（東京）での処理に切り替えられます（料金は同じ）。

「学習に使われない」の根拠として、Google Cloud の規約の条番号を書くか

3. アクセスの守り

入口会社・施設ごとの専用ページです。お渡しする QR コードの中の鍵で入ります。管理者用と職員用の2種類があり、使える機能を分けられます。鍵をなくしたときは、無効にして発行し直します
ほかの会社・施設見えません。サーバー側で鍵から会社・施設を決め、その区画だけを読み書きします
通信すべて暗号化（HTTPS）。住所は care.himawasa-sync.com です
提供者が見ること不具合の調査など保守のために、提供者が必要な範囲でデータを見ることがあります
2段階の本人確認今はありません（端末に保存した鍵で入る仕組みです）

提供者が見たときの記録の取り方

2段階の本人確認の方針（医療のガイドラインでは2027年4月から求められる）。公開するページに「ありません」と書くか

4. 運用

止まったとき提供者が前の版に戻して復旧します。稼働率のお約束（SLA）はありません。動く土台は Google Cloud です
控え（バックアップ）Google Cloud の中で二重化されています
変更のお知らせ機能の変更は、専用ページとメールでお知らせします
ご契約の終了お預かりしたデータを提供者が消去し、消去したことを書面でお知らせします。紹介状の一覧と名簿は、終了前に Excel で書き出せます

止まったときの対応時間（平日夜・土日はどうするか）

定期的な控え（バックアップ）を入れるか。今は「Google Cloud の中の二重化」だけで、定期の控え・時点への戻しは設定していない

5. お約束

  • お客さまの許可なく、データを分析・二次利用したり、第三者に渡したりしません。
  • 仕事を外に任せる先（再委託）は、動く土台の Google Cloud だけです。
  • 医療・介護の情報を扱うときは、国のガイドライン（いわゆる「3省2ガイドライン」）に沿って運用し、年に1回、自己点検を行います。
  • 病院向けには、ご契約時に安全管理の書類一式（サービスの内容の開示書・個人情報の取り扱いの覚書・責任の分け方の表・患者さま向けの掲示の見本）をお渡しします。

認証（プライバシーマーク・ISMS）は「ありません」。土台の Google Cloud は ISMAP・ISO 27001 などを取得。これを公開するページに書くか
